    Veelgestelde vragen
    
        
        
        
    
        
    
          
    Heb ik technische kennis nodig?
    Nee, ik leg alles in begrijpelijke taal uit.
    
          
    Wat heb ik nodig om te starten?
    Een apparaat met internet en de diensten die je wilt koppelen.
    
          
    Kan ik het daarna zelf beheren?
    Ja, uitleg hoort bij de hulp zodat je zelfstandig verder kunt.
    
          
    Verlopen mijn gegevens ergens heen?
    Bij het inrichten werk je in je eigen accounts; ik help je alleen door de stappen heen. Op deze website zelf worden geen gegevens verzonden of opgeslagen.
    
          
    Kan ik later uitbreiden?
    Ja, we kunnen later altijd bots, koppelingen of routines toevoegen.
    
          
    Is deze dienst van Grok Bot zelf?
    Nee, dit is een onafhankelijke dienst.
